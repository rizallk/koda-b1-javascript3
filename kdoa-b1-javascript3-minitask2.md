## Penjelasan fungsi dari setiap method dan function built-in di javascript

### 20 Built-in Method
```
1. Date.now()
Akan menghasilkan waktu saat ini dalam timestamps dan milliseconds.

2. Date.parse()
Akan menghasilkan waktu yang diparsing ke dalam bentuk timestamp

3. Math.round()
Akan mengembalikan nilai angka yang dibulatkan ke bilangan bulat terdekat.

4. Math.floor()
Akan mengembalikan nilai angka yang dibulatkan ke bawah.

5. Math.max()
Akan mengembalikan nilai terbesar dari deretan angka-angka sebagai parameter input

6. Math.min()
Akan mengembalikan nilai terkecil dari deretan angka-angka sebagai parameter input

7. string.toUpperCase()
Akan mengembalikan string yang telah dikonversi ke huruf besar semua.

8. string.toLowerCase()
Akan mengembalikan string yang telah dikonversi ke huruf kecil semua.

9. string.split()
Akan mengembalikan string yang telah dipisah-pisah tiap hurufnya ke dalam array.

10. string.replace()
Akan mengembalikan string baru dengan satu, beberapa atau semua kecocokan dari sebuah pola yang ditentukan.

11. array.push()
Akan menambahkan elemen ke dalam akhir array.

12. array.pop()
Akan menghapus elemen terakhir dari sebuah array.

13. array.forEach()
Akan melakukan perulangan pada array dengan menggunakan elemen dari callback.

14. array.map()
Akan mengembalikan array baru jika dilakukan manipulasi atau modifikasi pada array aslinya.

15. array.filter()
Akan mengembalikan array baru berdasarkan elemen yang dicari atau kondisi yang diinginkan pada array aslinya.

16. Object.keys()
Akan mengembalikan array yang berisi nama properti.

17. Object.values()
Akan mengembalikan array yang berisi nilai properti.

18. Object.entries()
Akan mengembalikan array yang berisi pesangan kunci dan nilai.

19. Object.fromEntries()
Akan mengubah daftar pasangan kunci-nilai menjadi sebuah objek.

20. boolean.toString()
Akan mengembalikan string yang mewakili nilai boolean yang ditentukan.
```

### 5 Built-in Function
```
1. Number()
Mengubah nilai menjadi tipe data number.

2. Boolean()
Mengubah nilai menjadi boolean true atau false. 

3. String()
Mengubah nilai menjadi string

4. isNaN()
Menentukan sebuah nilai apakah number atau bukan.

5. isFinite()
Menentukan apakah suatu nilai itu terbatas atau tidak.
```
